**两种口径,不要混着读:**
- **同步延迟**(ms/帧,及 1000/ms 的折算 fps):每帧 `tick()` 后等 GPU 跑完再计时,
  杀死 CPU/GPU 流水线重叠——衡量单帧往返耗时的上界,适合做算法 A/B 对比。
- **管线吞吐**(fps,3 帧在途泵送):每帧提交不等完成、在途满 3 帧排空一次,
  量 CPU/GPU 重叠下的饱和吞吐——playground 实际帧率受显示节流,低于此值属正常。
